# Support

Thanks for using `stui`.

`stui` is a small, terminal-native, Streamlit-inspired Python project. It is not
official Streamlit, not affiliated with Streamlit, and not a Streamlit
compatibility layer.

## Where to Ask

- Bug reports: use the bug report issue form.
- Feature requests: use the feature request issue form.
- Usage and contribution questions: use the question issue form.
- Security issues: follow `SECURITY.md` and avoid posting sensitive details in
  a public issue.

## Before Opening an Issue

- Check the README and existing issues.
- Try to reduce the problem to a small script or command.
- Include your Python version, `stui` version or commit, operating system, and
  terminal environment when relevant.

## Project Boundaries

`stui` does not aim to be a Streamlit compatibility layer. It also should not
add browser, server, websocket, or port-forwarding behavior.

Requests outside those boundaries may be closed so the project can stay small
and terminal-native.
