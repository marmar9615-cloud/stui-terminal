# v2.3 Interactive Workspaces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` or the coordinated isolated-worker
> workflow described below. Steps use checkbox syntax for tracking.

**Goal:** Ship v2.3.0 with safe tabs, local path input, selectable data tables,
non-sensitive diagnostics, and release-grade installed-user proof.

**Architecture:** Extend the existing immutable element records, runtime block
stack, widget state pipeline, and Textual renderer. Keep each flagship feature
as a bounded element/widget path and integrate shared exports only after focused
tests pass.

**Tech Stack:** Python 3.11+, Textual 8.2.5+, Rich, Typer, pytest, Ruff, build,
Twine, GitHub Actions, and Trusted Publishing.

## Global Constraints

- Preserve all v2.2 stable APIs and package/import/CLI names.
- No Streamlit, textual-slider, browser/server/websocket runtime, arbitrary
  shell execution, or heavy data/plotting dependency.
- Paths are local user input, not uploads or a security sandbox.
- Diagnostics must not serialize session/cache values, secrets, environment
  values, arbitrary reprs, or file contents.
- New APIs remain experimental until the release proof supports promotion.
- Optional browse, palette, mouse, watch-path, tabs nesting, and stretch work is
  cut before any mandatory correctness contract.
