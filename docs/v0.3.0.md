# stui v0.3.0

`stui` v0.3.0 focuses on terminal app primitives that make small tools feel
more structured without adding a browser runtime.

`stui` is terminal-native and Streamlit-inspired. It is not official Streamlit,
is not affiliated with Streamlit, and is not a Streamlit compatibility layer.
The PyPI distribution is `stui-terminal`; the import package and CLI are
`stui`.

## Added

| Area | API | Notes |
| --- | --- | --- |
| Forms | `st.form`, `st.form_submit_button` | Group inputs and get a one-shot submit signal. |
| Grouping | `st.container`, `st.expander` | Preserve nested render order in terminal layouts. |
| Metrics | `st.metric` | Show a label, value, and optional delta. |
| Charts | `st.bar_chart` | Render compact terminal-native bar summaries. |

## Forms

```python
import stui as st

with st.form("run-settings"):
    project = st.text_input("Project", "stui")
    batch_size = st.number_input("Batch size", min_value=1, max_value=128, value=16)
    dry_run = st.checkbox("Dry run", value=True)
    submitted = st.form_submit_button("Apply settings")

if submitted:
    st.success(f"Applied settings for {project}")
```

MVP limitation: widgets inside forms still update `st.session_state` as they
change. The submit button provides a one-shot submitted value; full deferred
form state is intentionally left for a later design pass.

## Grouping

```python
import stui as st

with st.container():
    st.subheader("Overview")
    st.progress(65, text="health")

with st.expander("Details", expanded=True):
    st.json({"status": "ok"})
```

Expanders are static in v0.3.0. They render open or closed based on the
`expanded` argument, but keyboard toggling is deferred.

## Metrics and Charts

```python
import stui as st

st.metric("Latest score", 13, delta="+2")
st.bar_chart([3, 7, 5, 11, 8, 13])
st.bar_chart({"baseline": 3, "candidate": 7, "shipping": 13})
```

`st.bar_chart` accepts lists of numbers, dictionaries of numeric values, simple
lists of dictionaries, and scalar fallback values. It does not depend on
pandas, matplotlib, plotly, browser canvas, SVG renderers, or web assets.

## Examples

```bash
stui run examples/forms.py

stui run examples/charts.py

```

## Still Out Of Scope

- Full Streamlit compatibility.
- Browser, server, websocket, or port-forwarding runtime.
- Sidebar, file upload, caching decorators, hosted auth, or cloud deployment.
- Interactive dataframe editing, sorting, or rich table browsing.
- `st.columns` and `st.line_chart`; both need more design before landing.
