# Release Notes

This folder keeps versioned release notes out of the repository root while
preserving the exact files used for GitHub Releases.

Use `RELEASE_NOTES_vX.Y.Z.md` for stable releases and
`RELEASE_NOTES_vX.Y.ZrcN.md` for release candidates.
