# Code of Conduct

## Our Pledge

We want participation in `stui` to be respectful, practical, and welcoming.
People should be able to report issues, ask questions, and contribute without
harassment or personal attacks.

## Expected Behavior

- Be kind and direct.
- Assume good intent while still being clear about technical tradeoffs.
- Keep feedback focused on the work, not the person.
- Respect maintainers' time and project scope.
- Remember that `stui` is Streamlit-inspired, not Streamlit-compatible.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Sexualized language or unwanted attention.
- Publishing someone else's private information.
- Repeatedly pushing requests that are outside the documented project boundary.
- Disruptive comments, spam, or bad-faith issue activity.

## Scope

This code of conduct applies to project spaces such as issues, pull requests,
discussions if enabled, and other official project communication channels.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other
reasonable action to keep the project space usable.

If you need to report a code of conduct issue and no private contact channel is
published, open a minimal public issue requesting a private maintainer contact
path. Do not include sensitive personal details in the public issue.

## Attribution

This document is inspired by common open source code of conduct patterns,
including the Contributor Covenant, but is intentionally kept short for this
project.
